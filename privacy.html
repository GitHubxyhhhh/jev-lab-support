Jev Lab 隐私政策

本政策适用于 XYH 提供的 Jev Lab iOS 应用。联系邮箱：dracorex@qq.com。应用免费，使用者自行配置第三方 AI 服务的 API Key；第三方服务可能另行收费。

更新日期：2026-10-13

1. 设备上的数据

你输入或导入的材料、问题和运行结果用于完成判断。TXT、可提取文字的 PDF 与本地 OCR 在设备内处理；原始文件不会作为历史附件保存。历史记录包含最终提交的材料文字、问题、结果和时间，最多保存 20 条，保存在设备的应用存储中。

TypeSafe 与可选视觉服务的 API Key 仅保存在本次应用运行的内存中，不写入历史记录或应用的持久化存储。应用进程结束或清除对应 API 设置后，需要重新填写密钥。切到后台不一定会结束进程。

应用不设置开发者运营的账号、广告、行为分析或云端历史同步服务。iOS 系统备份可能包含应用的本地历史；系统备份的保存与删除由你的 Apple 账户及设备备份设置控制。

2. 何时向第三方发送数据

运行判断时，材料文字、问题、选项和判断参数会通过 HTTPS 发送到 TypeSafe AI（api.typesafe.ai），用于生成判断结果；你的 TypeSafe API Key 随请求发送，仅用于该服务的身份验证。

只有配置并使用视觉识别或校正时，应用才会把待识别的图片或 PDF 页面的 JPEG 图像、待校正文字及处理指令发送到你指定的 HTTPS 视觉服务。该服务的 API Key 只发送到配置的服务地址。请确认地址、服务提供者及其隐私条款可信后再使用。

本次运行首次向一个服务地址发送材料前，应用会征求你的同意；拒绝时不会发起该次 AI 请求。网络服务会接收连接所需的信息（例如来源 IP），可能将请求与你的 API 服务账号关联。请勿提交你无权处理的个人信息或机密材料。

3. 第三方的保存与境外处理

XYH 不通过自有服务器接收或保存上述 AI 请求。第三方服务仍会处理收到的数据，不能因此认为没有第三方数据收集。TypeSafe 当前公开政策称，不使用用户输入训练或微调 AI 模型；其服务托管于美国，按服务和合法业务需要保存信息。这不代表零留存。

你指定的视觉服务可能有不同的日志、留存、模型训练和数据所在地规则，本应用无法替其作统一承诺。使用境外服务可能涉及境外传输；请阅读相应服务的政策和 API 服务协议，并确认你的使用符合适用要求。

4. 删除、撤回与权限

你可以在“历史记录”中删除记录或清空全部历史，在 API 设置中清除对应密钥。“撤销发送授权”会清除本次运行的地址授权，下次发送材料需重新确认。已经发出的请求无法通过本应用撤回，原生网络请求可能继续完成；第三方已保存的数据需按该服务的流程申请删除。

文件、照片或相机仅用于你主动选择的材料导入操作。应用不在后台自动扫描文件或读取相册，不调用定位、通讯录或 HealthKit 接口主动读取系统数据。你主动提交的材料仍可能包含个人或敏感信息。

卸载应用通常移除设备上的应用数据，但不会自动删除系统备份、你自行复制或导出的内容，以及第三方服务持有的数据。

5. 支持联系与政策更新

如有隐私问题或需要协助，请发送邮件至 dracorex@qq.com。你主动提供的邮箱、问题描述和附件会用于处理支持请求，并由所使用的邮件服务处理；不要发送 API Key、身份证件或包含敏感个人信息的完整材料。

本应用并非面向儿童设计。使用第三方 AI 服务时，请满足相应服务的年龄及其他使用条件。政策有变化时，将更新此页面及应用内副本，并标示更新日期。
